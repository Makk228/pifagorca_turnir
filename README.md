# Считай

Лёгкая веб-платформа марафонов ментальной арифметики. Java 21 / Spring Boot 3.5.16, файловая H2 / Flyway, стандартный SMTP и адаптивный HTML/CSS/JavaScript. Отдельные PostgreSQL и SMS.RU не нужны.

## Быстрый запуск

Нужны Docker Engine и Docker Compose v2:

```sh
docker compose -f compose.demo.yml up --build -d
```

Откройте http://localhost:8080. Демо слушает только localhost. Создаются два ребёнка, шестидневный марафон с сегодняшней даты, библиотека и задания.

| Роль | Почта | Демо-пароль |
|---|---|---|
| Родитель | parent@example.test | DemoParent2026! |
| Педагог | teacher@example.test | DemoTeacher2026! |
| Администратор | admin@example.test | DemoAdmin2026! |

Эти аккаунты создаются **только** при `DEMO_DATA=true` вне production. Демо-письма видны в Mailpit: http://localhost:8025.

Без Docker: Java 21 и Maven 3.9+, затем `scripts/dev.sh`. Данные H2 сохраняются в `data/`. Node.js для работы или сборки сайта не нужен. В этой рабочей папке также загружена локальная Java 21 в `.local/`; скрипт обнаруживает её автоматически.

## Что работает

- Регистрация родителя по почте и паролю от 6 символов. Вход по почте, восстановление кодом из письма, BCrypt, CSRF, сессии HttpOnly/SameSite и лимиты запросов.
- Раздельные версионируемые согласия и их отзыв; несколько детей у родителя.
- Независимые марафоны с датой, числом дней, timezone, несколькими педагогами, кодом вступления и управлением публикацией.
- CSV/XLSX-библиотеки, обязательное соответствие категории участника и категории файла, случайная выборка без повторов, массовое индивидуальное назначение.
- Ручное создание и копирование заданий. Начатые задания нельзя заменить.
- Серверный таймер, автосохранение с версией, продолжение на другом устройстве, защита от поздней записи, автоматическая проверка даже без открытого браузера.
- Раздельные правильные/ошибочные/пустые ответы; подробный разбор для родителя и педагога.
- Повторное открытие после подтверждённого сбоя: новая попытка, сохранение предыдущей, причина и аудит.
- Рейтинг с равными местами, учёт пропущенных дней, протокол очной встречи без изменения баллов, CSV общего/подробного отчёта.
- Почтовая outbox со стандартным SMTP, повторными попытками и локальным режимом. Провайдер меняется настройками, без изменения приложения.
- Администратор: роли, блокировка пользователей с отзывом сессий, педагоги марафона, аудит и состояние почтовой очереди.

## Как провести марафон

1. Администратор создаётся при первом production-запуске из `ADMIN_EMAIL`/`ADMIN_PASSWORD`.
2. Педагог регистрируется обычным образом; администратор меняет его роль в «Управлении».
3. Педагог создаёт марафон и передаёт родителям код вступления.
4. Родитель добавляет детей, указывает пол для аватара и вводит код марафона.
5. Педагог загружает CSV в «Библиотеки». В марафоне выбирает детей, день, файлы и параметры генерации либо создаёт задания вручную.
6. В настройках переводит марафон из черновика в «Опубликован · по расписанию».
7. В день задания родитель выбирает ребёнка и начинает работу. После отправки доступен разбор.
8. Педагог открывает рейтинг и отчёты. При равных итогах после окончания марафона фиксирует протокол очной встречи.

## Формат файлов

[Образец](samples/template.csv), [контракт](docs/contracts/API.md). UTF-8, разделитель запятая, первая строка строго:

```csv
category,topic,level,expression,answer
BABY,Сложение,BASIC,2 + 3,5
SCHOOL,Переход через десяток,MEDIUM,25 + 14 - 7,32
```

`BABY` / `SCHOOL`; `BASIC` / `MEDIUM` / `HARD`. Ответ — целое число, включая 0 и отрицательные. Не более 2 МБ / 10 000 строк. До 200 примеров в задании. Повторяющееся выражение+ответ из нескольких файлов попадает в выборку только один раз. У каждого ребёнка категория фильтруется отдельно. При нехватке примеров всё назначение отклоняется, существующие задания сохраняются.

## Проверки

```sh
scripts/test.sh
```

Тесты используют отдельную H2 в памяти. Отчёт JUnit: `target/surefire-reports/`; покрытие JaCoCo: `target/site/jacoco/index.html`. CI запускает тесты и собирает Docker-образ.

## Деплой

[Полная инструкция](docs/DEPLOYMENT.md). Подготовлены `compose.yml`, Dockerfile, Caddy, `.env.example`, healthchecks, backup и restore. Для реальной рассылки нужны домен и SMTP-аккаунт.

Для бесплатного теста можно использовать отдельный ящик Яндекса. Создайте пароль приложения и задайте SMTP-переменные: `SMTP_HOST=smtp.yandex.ru`, `SMTP_PORT=465`, `SMTP_AUTH=true`, `SMTP_STARTTLS=false`, `SMTP_SSL=true`; `MAIL_FROM` и `SMTP_USERNAME` должны содержать полный адрес одного и того же ящика. Пароль приложения передаётся только через секрет `SMTP_PASSWORD`.
