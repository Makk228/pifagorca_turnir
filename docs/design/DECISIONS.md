# Product Design: выбранное направление

05.11.2026: изучены index, user-context, get-context, ideate и image-to-code. Созданы три независимых визуальных концепта. По прямому поручению заказчика самостоятельно выбирать решения выбран первый (selected-reference.png), без остановки на подтверждение.

Кремовая основа #faf6ed, тёмно-зелёная навигация #133c2e, оранжевый CTA, крупные serif-заголовки, читаемый sans-serif интерфейс. Иллюстрация холмов с флагом создана отдельно через ImageGen. Основной экран: один главный CTA, шесть дней, дети, рейтинг. На мобильном боковая навигация превращается в компактную верхнюю.

Полный Java backend явно требуется пользователем: вместо prototype template используется Spring Boot со статическими HTML/CSS/JS и настоящими API. Sites/Workers не подходят для Java backend; поставляется Docker Compose.

Защита от расхождений макета с ТЗ: полные ФИО в опубликованном рейтинге, реальные результаты вместо выдуманных баллов, календарь по серверному расписанию, без детских отдельных логинов.

Финальные иллюстрации: `hero-source.png`, `avatar-boy-source.png`, `avatar-girl-source.png`; в приложение включены сжатые WebP. Иконки Feather обслуживаются локально, лицензия находится рядом с ними. [Визуальные итерации и скриншоты](../../design-qa.md).
